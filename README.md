## 🎭 The Concept

Welcome to the **Multiverse Portfolio**. This isn't just a website; it's a cinematic experience that bridges four distinct professional realities. Built with a focus on high performance, immersive animations, and futuristic aesthetics.

### 🌓 The Four Identities

| Identity | Focus | Theme | Status |
| :--- | :--- | :--- | :--- |
| **🔒 Cyber Architect** | Offensive Security & Recon | Matrix / Green Decay | `ACTIVE` |
| **🎨 Creative Director** | Visual Arts & Design | Glassmorphism / Vibrant | `ACTIVE` |
| **🎸 Sonic Engineer** | Music Production | Dark / Gold Visualizer | `ACTIVE` |
| **🚀 Aero Engineer** | Aerospace Systems | Starfield / High Contrast | `ACTIVE` |

---

## 🛠️ Tech Stack & Architecture

### **Core**
- **Next.js 15 (App Router)**: The foundation of speed and SEO.
- **React 19**: Modern component architecture.
- **Tailwind CSS 4**: Next-gen utility-first styling.

### **Graphics & Animation**
- **Three.js + R3F**: Immersive 3D environments.
- **Framer Motion**: Smooth orchestration of UI transitions.
- **React Spring**: Physical-based animation logic.

### **Infrastructure**
- **TypeScript**: Type-safe development.
- **GitHub Actions**: Automated CI/CD pipelines.

## 🚀 Getting Started

1. **Clone & Enter**
   ```bash
   git clone https://github.com/h-4k/Portfolio_v2.git
   cd Portfolio_v2
   ```

2. **Hydrate Dependencies**
   ```bash
   npm install
   ```

3. **Ignite Development**
   ```bash
   npm run dev
   ```

## 📦 Deployment Optimization

This project is optimized for high-performance deployment.

### **GitHub Pages (Static Export)**
The project uses `next export` to generate a lightning-fast static version.

```bash
# Set output: 'export' in next.config.ts
npm run build
```
